THE PROJECT

Beyond the first finding.

Security testing needs more than a list of alerts. I built WebShield to connect assessment, analyst verification, evidence, remediation and retesting in one workflow for authorized web application testing.

MY CONTRIBUTION

What I built.

  • Built a React/Vite frontend and a Python/FastAPI security engine.
  • Implemented passive HTTPS, header, cookie and CORS checks, plus authentication and JWT analysis.
  • Added controlled authentication rate-limit testing and two-account access-control assessment.
  • Generated potential findings with analyst Confirm/Dismiss verification and evidence management.
  • Connected remediation and retesting to security assessment report generation.
